# Lesson 3 - Prompt Engineering

## Formula

Role

Task

Context

Constraints

Output Format

## Example

Role:
Senior TypeScript Engineer

Task:
Review this code

Focus:

- Bugs
- Performance
- Security

Output:

- Rating
- Issues
- Improvements
- Refactored Code

## Good Prompt Characteristics

- Clear
- Specific
- Gives enough context
- Specifies output format
- Defines constraints

## Bad Prompt

Review this code.

## Better Prompt

You are a Senior TypeScript Engineer...

## Practice Prompts

- AI Email Writer
- Code Reviewer
- Text Summarizer
- Docker Tutor

## Key Takeaways

Prompt quality directly affects response quality.
